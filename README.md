# Image Colorization with PyTorch

Проект по автоматической колоризации чёрно-белых изображений с использованием PyTorch. Исследуются архитектуры U-Net, различные подходы к обучению и методы улучшения качества колоризации.

## Задача

Модель получает канал яркости `L` из цветового пространства LAB и предсказывает цветовые каналы `a` и `b`, необходимые для восстановления RGB-изображения.

- **Датасет:** [PASCAL VOC 2012](https://www.robots.ox.ac.uk/~vgg/projects/pascal/VOC/voc2012/#devkit).
- **Размер изображений:** 128 × 128.
- **Вход:** `L` — `[B, 1, 128, 128]`.
- **Выход:** `ab` — `[B, 2, 128, 128]`.

## Baseline: U-Net

Реализована собственная U-Net с тремя уровнями downsampling, skip connections и `base_channels=32`, без BatchNorm.

**Обучение:** L1 Loss, AdamW (`lr=1e-3`), batch size 32, 20 эпох. Эксперименты проводятся в Google Colab, метрики отслеживаются в W&B.

| Эксперимент | Эпохи | Train L1 | Val L1 |
|---|---:|---:|---:|
| U-Net baseline | 20 | 0.06448 | 0.06289 |

*Метрики последней эпохи, рассчитанные на нормализованных каналах `ab`.*

### Результаты

Модель частично восстанавливает характерные цвета объектов, однако предсказания остаются достаточно приглушёнными, с преобладанием зеленоватых и коричневых оттенков.

На исследованном validation-батче дополнительное обучение снизило L1 с **0.06259 до 0.06227**, тогда как grayscale baseline (`a = b = 0`) получил **0.06416**.

Визуально заметны улучшения в восстановлении отдельных оттенков, но модель по-прежнему склонна предсказывать цвета, близкие к нейтральным.
