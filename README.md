# Image Colorization with PyTorch

Проект посвящён автоматической колоризации чёрно-белых изображений с использованием PyTorch. В рамках работы исследуются архитектуры на основе U-Net, различные подходы к обучению и применение предобученных моделей для улучшения качества колоризации.

## Задача

Модель получает канал lightness **L** из цветового пространства CIELAB и предсказывает два цветовых канала **a** и **b**. Вместе с исходным L они позволяют восстановить цветное изображение.

- **Данные:** [PASCAL VOC 2012](https://www.robots.ox.ac.uk/~vgg/projects/pascal/VOC/voc2012/#devkit).
- **Размер изображений:** 128 × 128 (Resize + CenterCrop).
- **Вход:** `L` — `[B, 1, 128, 128]`, нормализация `L / 100`.
- **Выход:** `ab` — `[B, 2, 128, 128]`, нормализация `a / 128`, `b / 128`.

## Текущий baseline

Custom **U-Net** на PyTorch: блоки `DoubleConv`, `Down`, `Up`, bottleneck и skip connections с конкатенацией. Три уровня downsampling, `base_channels=32`, без BatchNorm.

**Обучение:** L1 Loss, AdamW (`lr=1e-3`), batch size 32, 20 эпох. Эксперимент выполнен в Google Colab с GPU; метрики отслеживаются в Weights & Biases (W&B). Сохраняются `best` и `last` checkpoints.

### Анализ baseline

После 20 эпох обучения модель частично восстанавливает характерные цвета объектов, однако предсказания получаются преимущественно тусклыми и недостаточно насыщенными.

На батче из 32 изображений validation-выборки:

- Среднее абсолютное значение предсказанного канала `a` оказалось примерно в **3.9 раза меньше**, чем у оригиналов.
- Для канала `b` — примерно в **1.7 раза меньше**.
- L1 Loss модели составил **0.06259**, тогда как полностью серое предсказание (`a = b = 0`) получило **0.06416**.

Таким образом, на исследованном батче U-Net уменьшила L1 Loss относительно полностью серого baseline всего на **2.45%**.

Одна из возможных причин низкой насыщенности — использование L1 Loss, при котором модели может быть выгоднее предсказывать нейтральные оттенки для объектов с неоднозначным цветом. Также на качество могут влиять ограничения encoder и недостаточное обучение.

Полученные результаты показывают, что **низкий L1 Loss не гарантирует хорошего визуального качества колоризации**. Для окончательной оценки потребуется проверить результаты на всей validation-выборке и провести дальнейшие эксперименты.
